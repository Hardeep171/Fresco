# FRESCO

A production-ready Laundry & Garment Care Platform built with modern backend architecture and industry best practices.

## 🚀 Project Overview

FRESCO is a scalable laundry management platform designed to simplify the complete laundry lifecycle—from pickup scheduling to delivery tracking.

This project is being developed with a production-first mindset, following clean architecture, modular design, and enterprise-level coding standards.

---

## 🛠 Tech Stack

### Backend
- Node.js 22 LTS
- Express 5
- TypeScript
- MongoDB
- Mongoose
- Zod
- Winston
- JWT
- bcryptjs
